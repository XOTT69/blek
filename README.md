# Поруч

Mobile-first PWA для швидких анонімних повідомлень про світло, воду й зв’язок у районі та пошуку місць поруч. Стан сервісів стає live-даними після підключення Supabase; назви місць, координати й адресний пошук надходять з OpenStreetMap через серверні маршрути Vercel.

## Дані та приватність

- Застосунок зберігає обрану локацію лише у `localStorage` браузера; точна адреса не потрапляє у звіти.
- Місця поруч сортуються за реальною відстанню, а натискання на них відкриває точку в OpenStreetMap. Режим роботи варто перевіряти перед візитом.
- Анонімний користувач може надіслати один статус для кожного сервісу раз на дві хвилини. Це захищає від випадкових повторів і простого спаму.
- Немає повідомлень від сусідів — інтерфейс чесно показує «ще немає даних», а не вигадані значення.

## Запуск

Це статичний проєкт без залежностей. Для PWA-функцій відкрийте його через локальний сервер:

```sh
python3 -m http.server 8080
```

Потім відкрийте `http://localhost:8080`. Локально застосунок працює в деморежимі, а зміни зберігаються лише в `localStorage` браузера.

## Підключення Supabase

1. Створіть Supabase-проєкт у регіоні ЄС.
2. Увімкніть **Anonymous sign-ins**: Authentication → Providers → Anonymous.
3. Відкрийте SQL Editor, вставте та виконайте [supabase/schema.sql](./supabase/schema.sql).
4. Скопіюйте Project URL та publishable (або legacy anon) key з Settings → API.

## Деплой на Vercel

1. Імпортуйте GitHub-репозиторій у Vercel.
2. Додайте `SUPABASE_URL` і `SUPABASE_ANON_KEY` з [.env.example](./.env.example) до Environment Variables для Production, Preview та Development.
3. Натисніть Deploy. Vercel автоматично віддасть статичний PWA та `/api/config`.

Ніколи не додавайте `SUPABASE_SERVICE_ROLE_KEY` у Vercel або браузер. RLS-політики та `submit_status_report` дозволяють користувачам лише створювати власні анонімні повідомлення з обмеженням частоти.
